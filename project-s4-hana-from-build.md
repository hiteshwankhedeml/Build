# Project - S4 Hana from BUILD

* SAP Build Tower ⇒ Lobby ⇒ Destination ⇒ Here the destination would is visible
* Only the destination which are having sapbuildprocessenable will be visible here
* In SAP API Hub, we can see all the APIs available for example for SAP S4 Hana Private edition
* Download the EDMX file for the API
* In /n/iwfnd/maint\_service — Check the service
* Create Action, Choose API source as "Upload API specification"
* Upload the edmx file downloaded earlier
* Inside action, select which all calls we want to use
* Define input, output and then test
* During testing we need to select destination&#x20;
