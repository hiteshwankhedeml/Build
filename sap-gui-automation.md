# SAP GUI Automation

* SAP GUI for Windows application can be automated in SAP intelligent RPA using the SAP GUI connector and the recorder
* Both rely on SAP scripting which depends on the version of SAP GUI for windows client
* SAP recommended using SAP GUI for windows 7.40 and above
* Scripting should be enabled
