# Excel SDK

* Collection of activities allowing you to create automations using microsoft excel
* It comes with a rich set of functionalities
  * Create new excel workbook
  * Create new excel worksheet
  * Read and write data from excel sheet, for a given date range
  * Apply filters



**Excel Data Mapping:**

* Allow to transform columns based data from an excel sheet into datatype that can be used in automation
* The data from the excel sheet stays the same but the structure becomes a data type structure, making it possible to use throughout the project
